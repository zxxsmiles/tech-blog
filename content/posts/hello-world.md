这是博客的第一篇文章，用来验证 Hugo + GitHub Pages 的自动部署链路。

<!--more-->

## 发布流程

1. 在 `content/posts/` 下新建 Markdown 文件
2. 提交 Pull Request
3. 合并到 `main` 分支后自动部署

## 代码块示例

```bash
hugo new posts/my-new-post.md
hugo server -D
```
